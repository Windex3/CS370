# CS370

## Briefly explain the work that you did on this project: What code were you given? What code did you create yourself?
For this project, I was given starter code for the maze environment, experience replay, and supporting functions. I implemented the deep Q-learning training algorithm that allowed the pirate agent to learn how to navigate the maze and find the treasure. 

## What do computer scientists do and why does it matter?
Computer scientists develop software and algorithms to solve problems. Their work matters because technology helps improve efficiency, automate tasks, and solve complex problems across many industries.

## How do I approach a problem as a computer scientist?
I approach problems by breaking them into smaller steps and determining the best way to solve each one. This project reinforced the importance of testing, debugging, and adjusting code when something does not work as expected.

## What are my ethical responsibilities to the end user and the organization?
My responsibilities include developing reliable and secure software, protecting user information, and considering how technology affects others. It is also important to test software thoroughly and be transparent about its limitations.
